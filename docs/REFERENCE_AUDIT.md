# Reference audit

## Requirements accepted

- DRAKON is structural program editing rather than freehand flowchart connectivity.
- Normal flow reads downward; preferred flow stays on the skewer; truth and preference are separate.
- Layout quality is testable through metre, rhythm, air, equal widths, common fate, clearance, and crossing rules.
- The 27 atomic icons and 21 macroicons form a completion inventory.
- New constructs insert immediately with valid contextual Python and are edited afterward.
- Diagram, source, and live-test views form one outer document.
- The whole project generates deterministic Python artifacts after a saved, valid revision.
- A visible Module Setup replaces magic property markers.
- One command service supports GUI, keyboard, CLI, Python, JSON-RPC, and MCP actors.

## Requirements rejected

- Legacy `.drn` compatibility.
- Geometry-defined semantic connectivity.
- Hidden project properties.
- Independent floating of diagram and associated code/test views.
- Automatic execution while opening, saving, validating, or generating.
- A watched filesystem inbox as the live collaboration protocol.
- Copied historical artwork or UI composition.

## Prototype lessons converted into gates

- A new project exposes an editable `main()` immediately.
- Opening a project leaves no Untitled phantom.
- Unmodified two-finger scroll pans instead of zooming.
- Horizontal and vertical eligible route segments both carry insertion metadata.
- Palette and existing-object drags show a scaled ghost.
- Fit bounds include connectors and buses.
- Text never crosses an icon's internal strokes.
- The Inspector defaults to the lower left.
- Generated-folder reveal is unavailable until a non-empty manifest exists.
- Command-palette search remains focused while Up, Down, and Enter operate results.

## Final visual/provenance review

- Every inventory entry appears once in the contact sheet from the same solved recipes
  used by canvas, palette, ghost, and SVG.
- Long text, Unicode, multiline code, Shelf compartments, loop labels, Output/Input
  dividers, parallel bars, notches, ports, buses, and high-DPI bounds have collision
  coverage.
- Connector-aware fit includes route extremes; free-form crossings use deterministic
  bridge geometry in canvas and every export projection.
- No legacy parser/exporter, copied artwork, runtime prototype import, or historical
  schema token is present in the redesign root.
