# Product glossary

**Address** — A typed silhouette transition naming the next branch or finite exit.

**Air** — Reserved whitespace between text and every outline, divider, bar, arrow, badge, and port.

**Block** — A DRAKON structure with one top entry and one normal bottom continuation.

**Canonical state** — The authoritative semantic model from which views, files, diagnostics, and code derive.

**Command** — The only operation allowed to mutate canonical state.

**Common fate** — Alignment of corresponding branch nodes so they are perceived as related.

**Insertion boundary** — A semantic location between operations, projected onto eligible route segments.

**Liana** — A secondary orthogonal route leading to a legal join or exit.

**Macroicon** — A typed composite created atomically with all required bodies and joins.

**Metre** — Repeated clear vertical spacing between neighboring icons on one skewer.

**Preferred or happy path** — The ordinary expected route kept straight down; it is independent of truth.

**Rhythm** — Wider repeated spacing separating sibling branch columns or silhouette skewers.

**Shelf** — A typed assignment icon whose upper compartment names the target and lower computes the value.

**Silhouette** — Ordered named branches linked by explicit Address transitions and visual buses.

**Skewer** — The straight vertical backbone of normal DRAKON execution.

**Valence** — The attachment contract describing what may be inserted at a semantic boundary.
